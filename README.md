A make.fun entry for [Worst Fix Ever: Funniest Commit Message](https://make.fun/c/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722): one line of commit message for a bug fix that made everything worse.

## The entry

`main.py` (Python 3, standard library only) writes a single original commit-message line to `/output/entry.txt`:

> fix: stop duplicate charges by billing everyone twice at once

## Run it

```sh
python3 main.py
```

It writes `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
